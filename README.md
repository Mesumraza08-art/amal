# Amal Global Investments — Website

Self-contained static site (single `index.html` with hash routing).

## Deploy to Hostinger

**Option A – Git (recommended):** hPanel → Websites → Advanced → **Git** → add repository
`https://github.com/Mesumraza08-art/amal.git`, branch `main`, install path empty (deploys to `public_html`).
Click **Deploy** (or enable auto-deployment via the webhook shown there).

**Option B – File Manager:** upload `index.html` and `.htaccess` into `public_html`.

Enable the free SSL certificate in hPanel → Security → SSL before visiting the site.
